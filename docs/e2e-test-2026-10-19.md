# 公开 Web 主链路端到端测试记录

## 测试场景

默认上证指数、近 60 个交易日，提交“请基于本轮有效证据概括当前市场状态、主要矛盾和重新评估条件，不做涨跌预测或仓位建议”。实际研究区间由交易日历解析为 2026-07-17 至 2026-10-19。

## 实测结果

网页提交和实时研究请求成功，HTTP 200。AI 计划、扶摇交易日历、指数日线、对比指数、全市场快照、涨停统计、快讯候选和报告步骤均返回。页面生成 21 条可追溯证据，涵盖指数行情、宽度、大小盘代理、成交额、情绪和 10 条近期资讯候选；指数估值未接入。

DeepSeek 的完整报告未通过报告结构或引用校验。系统随后发起简化结论恢复请求，DeepSeek 返回了通过边界检查的最终结论；页面明确标记为“LLM 修复结论已生成”，并说明完整报告校验失败及恢复方式。报告摘要关联的证据编号覆盖指数收益、最大回撤、市场宽度、风格差、成交额、封板率、连板高度和快讯候选。

本轮七维证据覆盖为 86%，结论证据强度为“中”。市场宽度只有单日快照且估值缺失，因此结论明确限制强度。重新评估条件区显示最近交易日上涨参与度为 40.88%，触发线为超过 50%，当前未满足。页面保留数据时点、口径、证据抽屉、规则标签和继续研究入口，研究表单在请求结束后恢复可提交。

**本次公开 Web 端到端主链路通过。** 取数完成、报告结构失败后的模型修复结论可见、摘要证据编号可追溯、置信度和状态复核条件可见；服务端对应恢复成功分支结束为 complete。该结论只说明本轮软件链路跑通，不代表七维数据齐备，也不代表行情方向判断正确。

## 本次代码修复

- 完整模型报告结构或引用失败时，再向模型请求一个短结论，并由服务端补齐本轮观察、缺失维度和复核条件。
- 简化请求仍无效时，根据已校验的真实证据及规则标签生成明确标记的规则兜底结论；模型网络或响应异常时也保留结论输出。
- 页面和 Markdown 导出显示生成方式及恢复原因，报告摘要为本轮结论附上覆盖核心市场判断的证据编号。
- 回归测试覆盖模型修复、规则兜底、未知证据、越界数字、违规交易建议、坏 JSON 和网络失败。
