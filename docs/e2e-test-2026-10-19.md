# 公开 Web 主链路端到端测试记录

测试时间：2026-10-19 17:10—17:12（北京时间）
测试环境：[市场证据台公开站](https://market-evidence-desk-20261018.minty-genet-8078.chatgpt.site/)
测试方式：Playwright 实际打开网页、提交问题并检查页面结果；本次不是历史事件回填测试。

## 测试场景

在默认上证指数、近 60 个交易日范围内提交两次市场综述问题：先询问指数变化与市场参与度是否一致，再询问当前市场状态、主要矛盾和重新评估条件。第二次使用更简洁的问题复测 AI 最终结论。

## 实测结果

网页打开成功，研究请求及扶摇数据取数成功，AI 研究计划成功。实际研究区间为 2026-07-17 至 2026-10-19，页面显示 21 条可追溯证据。可用项包括指数行情、最近交易日市场宽度、沪深 300／中证 1000 风格比较、指数成交额代理、涨停统计和 10 条近期 A 股快讯候选；指数估值仍未接入。

页面展示的代表性结果包括：20 日指数区间收益 -4.04%、区间最大回撤 -7.09%、年化波动率 12.04%、最近交易日上涨比例 40.88%、大小盘代理收益差 -2.37 个百分点、指数成交额相对前 20 日均值 0.84 倍。页面给出“上涨参与度超过 50% 时复核”的状态条件，当前 40.88%，条件未满足。数字均应结合各自证据时点与口径理解。

**两次请求的扶摇取数均完成，但 DeepSeek 最终报告都未通过报告结构校验。** 页面保留了数据、规则标签、事件候选和复核条件；AI 最终结论没有生成，结论证据强度也未计算。因此本次结论是“数据链路通过，完整端到端主链路未通过”，不能按完整验收通过提交。

## 结论与待处理

- 已验证：公开 Web 可访问；问题提交、AI 计划、行情和其他已接入维度取数、证据展示、数据时点、状态复核条件均可运行。
- 未通过：AI 最终结论在两次实际请求中均被报告结构校验拦截。需继续定位 DeepSeek 返回 JSON 与报告 schema 不匹配的字段，修正后重新运行完整主链路。
- 数据缺口：指数估值未接入；事件只读取近 72 小时快讯候选，没有持续历史事件沉淀；事件候选的重大性和多源交叉核验未完成。
- 本轮没有测试或声称历史新闻回填成功，也没有使用当前新闻填充历史研究。
