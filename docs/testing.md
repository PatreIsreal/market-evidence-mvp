# 测试说明

测试代码位于 `tests/unit/`。单元测试使用合成数据和模拟 HTTP 响应；它们不代表供应商授权，也不代替部署环境冒烟。

## 本地命令

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

Vitest 使用独立的 `vitest.config.ts`，不加载 Sites 的 Cloudflare Worker 插件配置。
