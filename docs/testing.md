# 测试说明

测试代码位于 `tests/unit/`。单元测试使用合成数据和模拟 HTTP 响应；它们不代表供应商授权，也不代替部署环境冒烟。

## 本地命令

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

Vitest 使用独立的 `vitest.config.ts`，不加载 Sites 的 Cloudflare Worker 插件配置。

## 已覆盖行为

- 收益、均线、回撤、波动、上涨宽度、同样本均值、成交额比值和置信度质量传播。
- 日期校验、无效日历日期、倒置区间、未来日期和不支持的回看周期。
- 合成数据显式标识、未接维度和来源说明。
- NDJSON 多事件、任意分片、尾行无换行、中断流、无效事件和 HTTP 错误提示。
- 扶摇字段映射、快照宽度、历史宽度不回填、缺少 Key、非 HTTPS 配置、业务错误与不完整快照。
- 模型 JSON 输出、证据引用存在性、交易建议拦截、合成数据隔离和 Markdown 报告导出。

## 尚未完成

- 历史区间研究只提供指数历史日线，扶摇当前快照不能回填该历史阶段的逐日市场宽度；页面明确标记缺口，置信度随之降低。
- 2026-10-19 最新公开 Web 端到端复测中，DeepSeek 报告结构校验连续两次失败；在修复并重测前，不应把公开版标记为当前完整主链路验收通过。
- 事件数据目前是近 72 小时候选读取，没有每日持久化和历史事件查询；服务器旧新闻库也不代表当前应用已具备历史事件沉淀。
- 历史区间浏览器请求曾出现一次连接超时，随后重试成功；本轮本地 Playwright 多轮请求及最新服务器部署后的真实研究流均完成。
- iFinD MCP 尚未连接；本机技能鉴权请求返回 HTTP 401。指数估值历史仍未接入；情绪与事件本轮只完成本地适配和单测，尚未在更新后的线上应用流中复测。
- 双源相同指标产生冲突时的双方值展示尚未验证；当前只有扶摇数据源，须待第二个有效数据源接入后验收。
- 扶摇数据在页面、导出中的账户授权范围以及评审外部访问条件尚未确认。
- 公开站点目前没有登录或请求限流；访客研究会使用服务端配置的上游额度。
