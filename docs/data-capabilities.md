## 当前 live 行为

- `APP_DATA_MODE=live` 且有 `FUYAO_API_KEY` 时，服务端按文档请求日历、主指数与比较指数历史日线，并在允许的最新日期读取全市场快照。
- Key 只发送在服务端请求的 `X-api-key` 头中。浏览器 health／capabilities 只收到“是否配置”的布尔状态，不会收到密钥值。
- 上游 HTTP 错误、业务错误、响应结构错误或超时会作为失败展示，不会回退到演示序列。
- 市场宽度只从最新快照计算；历史区间如果早于最近已完成交易日，宽度标为不可用。
- 扶摇估值 API 当前是个股最新估值快照，本版没有建立指数估值映射；情绪、事件与运行时模型仍未接入。
- `IFIND_MCP_URL`、`IFIND_ACCESS_TOKEN` 是预留变量；当前 live 路由没有 iFinD 实现，单独设置它们不会启用数据适配器。

## 接入与验证规则

1. 真实 API Key 只放在未跟踪的 `.dev.vars` 或托管 secret 中，不要粘贴到聊天、源码、日志或导出。
2. 配置凭据不等于已验证。只有完成实际请求并核对权限、代码、字段、时间与展示授权后才标记为验证通过。
3. 供应商数据按最小必要字段返回页面；完整原始响应不写入仓库和报告。
4. 无数据、过期、冲突、接口失败和未支持字段保留显式状态，禁止用合成值补入 live 结果。
