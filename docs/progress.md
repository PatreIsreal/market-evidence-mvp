- iFinD MCP 未连接；指数估值历史尚未接入。情绪与快讯候选已在本地代码接入，但历史趋势、重大性核验、交叉来源与数据展示授权仍缺。iFinD 资讯事件检索不是公开 API/MCP/CLI 能力。
- 服务器新闻表最新入库停在 2026-10-01；最新雪球文章发布日期停在 2026-09-20，恢复采集并补全来源链接后才可用于当前事件研究。
- 扶摇数据展示授权范围仍待确认；10-19 公开研究中的全市场快照被判为 stale，且当前市场快照无法补成历史宽度；双源冲突展示尚未实测。自托管版本未更新到新增情绪和事件候选的版本。
