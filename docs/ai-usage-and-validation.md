## 产品运行时 AI

运行时适配器使用服务端配置的 OpenAI Chat Completions 兼容接口，并要求 JSON Object 响应。测试以可控 HTTP 替身验证协议解析、凭据只进入服务端请求、引用不存在的证据会被拒绝、越界交易建议会被拒绝，以及演示数据不会被发送给模型。DeepSeek 官方默认启用思考模式；本项目通过可选 `MODEL_THINKING_MODE=disabled` 关闭该模式，使短 JSON 结构化归纳稳定通过校验。真实密钥不记录在此文档中。
