## 产品运行时 AI

运行时适配器使用服务端配置的 OpenAI Chat Completions 兼容接口，并要求 JSON Object 响应。测试以可控 HTTP 替身验证协议解析、凭据只进入服务端请求、引用不存在的证据和越界交易建议不会进入结论，以及演示数据不会被发送给模型。完整报告无效时先请求简化模型结论，再失败则从经校验事实生成带来源标记的规则兜底报告。DeepSeek 官方默认启用思考模式；本项目通过可选 `MODEL_THINKING_MODE=disabled` 关闭该模式。真实密钥不记录在此文档中。
